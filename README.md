# graphometer.ai

Source for the Graphometer site at https://graphometer.ai/ — free, open
tools, resources, reports, and data that show what AI systems actually do.

- `site/` is the deploy set; Cloudflare Pages serves it as-is (no build step).
- The site is static by promise: no scripts, no tracking, no cookies.
- Every page is reviewed (a voice pass and a hostile red-team read) before
  it lands here, and every published number traces to a recorded run.
