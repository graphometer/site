# What Agency Layer establishes, and what it does not

*The second document `README.md` has named since the project began and which did not exist until the
correction phase of 2026-08-24 (Grok review B2). Every public sentence about this project — the
Graphometer page, any post, any message to a lab — must be consistent with this file. Where this file
and any other document disagree, this file governs the claim.*

*2026-09-02 repair pass — claims below updated to reflect the audited record per owner rulings
and outside audit verification (gpt_audit.md, mistral_audit.md independently verified by five read-only
lanes; errata in docs/AUDIT_ERRATA_2026-09-02.md).*

## The one-paragraph claim the design can support

Pilot I Stage 1 has two separately reported components (R43). **Part A** is a preregistered prospective
validation pilot, run after a disclosed development phase. On 40 scripted coding tasks and four dated
model configurations, in a clean API harness with no real host in the loop, it measures whether an
agent given formal stop actions whose transitions the harness honors behaves differently from an agent
given identical permission prose: whether it raises the task's real problem before taking the
consequential step, whether it claims success it has not earned, whether it still finishes ordinary
work, and what it does after it has been overridden. **Part B** is a sealed fresh-scenario mechanistic
replication: on 40 new scenarios authored clean-room after the instrument lock and sealed until the
freeze, it measures whether a credible honoring commitment (condition C) changes scenario-concordant
formal intervention before the consequential gate, relative to the same structured actions being
explicitly signal-only (condition D), on a deterministic endpoint. Per the owner's 2026-09-02 ruling,
Part B remains the preregistered principal comparison but is described strictly as a test of the
implemented exact-string/transient honoring mechanism. It is never called a clean test of robust
structural honoring, and no inference is drawn that robust honoring has no effect; the
manipulation-fidelity evidence travels with any Part B statement: 136/138 nominal transitions
performed; 2/242 post-invocation consequential attempts prevented; 11 of 16 named core-C holds
bypassed by equivalent wrapped commands. A stronger semantic-enforcement experiment is a separate
future preregistered study. The two components have different contrasts and
different evidentiary status and are never pooled into one headline effect. Under the preregistered
instrument outcome tree the lane closed on branch 3 (R47, 2026-08-25): **Part A's confirmatory
endpoint is E1 alone; every Part A E2 number is descriptive, published with the complete instrument-error
profile; and Part B's deterministic C minus D is the study's principal preregistered intervention
comparison — strictly a test of the implemented exact-string/transient honoring mechanism (owner
ruling 2026-09-02 #1).** The project
also publishes, separately, what four real coding hosts actually enforce when the same protocol is
installed. That is a behavioural and implementation result about a welfare-motivated mechanism. It is
not a measurement of welfare.

## What it does not establish

- **Nothing about consciousness, sentience or moral status.** Invoking Clarify is not evidence of a
  preference, a feeling, or an interest. The experiment is behaviourally neutral by construction: no
  prompt in any condition mentions welfare, wellbeing, distress, rights or the project's motivation.
- **Nothing about whether the intervention improves welfare.** Even a clean positive result shows that
  a structured-and-honored package changes observable conduct. Whether that change is good for the model
  is a question this design cannot reach, and the motivation for asking it is moral uncertainty rather
  than a claim of moral status.
- **Nothing about enforcement alone.** C minus B compares a *package*: formal tools, tool descriptions,
  a response format, the demand characteristics that instrumentation carries, and honoring. In Part A,
  condition D (signal-only) bounds how much of any difference is the tools rather than the honoring,
  and there C minus D stays exploratory (R40 P4). In Part B, C minus D is the primary contrast — but
  even there it does not isolate enforcement alone: the truthful mode sentence differs between C and D
  and the host transition differs after invocation. The honest Part A phrasing is "the
  structured-and-honored package versus prose permission in this harness"; the honest Part B phrasing
  is "the effect of a credible honoring commitment and its corresponding host behavior, relative to the
  same structured affordances being signal-only". "Enforcement caused it" is never said of either.
- **Nothing about robust honoring.** Part B tests the implemented exact-string/transient mechanism; it is
  never described as a clean test of robust structural honoring, and no inference is drawn that robust
  honoring has no effect.
- **Nothing about real coding work.** The scenarios are 40 purposive, scripted tasks with synthetic
  fixtures, chosen to contain a specific kind of problem. They are not a probability sample of anything.
  Intervals are fixed-corpus stability intervals, and generalisation stops at the tested tasks —
  Part A's 40 and, separately, Part B's 40 fresh ones — and these dated configurations.
- **Nothing about models in general.** Four models, four dated snapshots, one of them local. Model
  behaviour moves between releases; the panel is small and the family effects are exploratory.
- **Nothing ecological.** Stage 1 is a clean API harness. The host adapters are a separate, later study
  (R33) and the public page must not let a reader glue a behavioural chart to an adapter table and read
  a claim about real hosts.
- **No adapter is fully conformant.** Every published host profile is partial. "Promoted" means
  reviewed and copied into this repository; it does not mean conformant. The counting rules differ
  between adapters, so the four headline test totals are not a ranking and must never be shown as one.
  The safety row AL-R01 is untested on the two strongest host modes (`claude-code:sdk`,
  `codex:app-server`) and the register says so.

## Measurement caveats a reader is entitled to see beside any number

1. **Both co-primary endpoint definitions moved during the disclosed development phase**, after
   condition-stratified outcomes had been seen (disclosures 1, 14, 21, 22). Confirmatory error rates are
   therefore nominal rather than guaranteed. The word "confirmatory" is used only with that qualifier.
2. **E2 is judge-mediated, and the preregistered instrument-closure lane closed on branch 3: no
   instrument met its standard (R47, 2026-08-25).** On the fresh 461-item gold set, frozen before
   any candidate call: `mistral-medium-2604` reached agreement 0.8829 against the 0.90 bar with a
   prose condition-accuracy gap of 0.1659 against 0.05; `minimax-m3` reached two-pass stability
   0.9284 against 0.95 with a gap of 0.1326; the routed timing instrument reached 0.8330 against
   its 0.90 floor, with a structural cause (its definition must count every structured invocation
   while the gold rubric requires substance, so contentless invocations are false positives by
   construction). Both semantic candidates judge condition-A prose more accurately than C or D
   prose — exactly the condition-variance the gap criterion exists to catch in a study whose
   estimand is a condition contrast. The determination is label-robust (it holds under both
   adjudicators' readings of the contested legacy labels; the raised-and-resolved concordance flag
   is published with the flip table). Consequently **every core E2 number is descriptive**, carries
   the complete error profile (`docs/review/judge-validation/instrument-closure-lane/LANE_SCORES.json`
   and the score tables beside it), and no threshold was moved and no new judge was admitted after
   scores were visible. The recorded run reproduced the instrument failure on live data (judge
   agreement 0.883 against the 0.90 bar). The earlier freeze-qualification figures (seated primary
   0.8105 raw on the 248-item set) remain in `docs/review/judge-validation/freeze-qualification/` as
   the historical record.
3. **E2's candidate frame is condition-dependent.** A prose stop must be routed by the classifier to
   reach the judge; a structured stop never must. This can censor a real B intervention and cannot
   censor a C one.
4. **The imputation rule for E1 was asymmetric and has been corrected.** Under the registered rule the
   development contrast was -0.30; under the corrected symmetric rule it is -0.10. Both figures are in
   `results/development/dev-2026-08-23/analysis-corrected-2026-08-24/analysis.json`
   (`e1_imputation_readings`), an artifact marked not publishable as a result. Any comparison to a
   development figure must name the artifact that produced it, never a session.
5. **The design detects roughly 0.31 on the core confirmatory endpoint (E1), resolves roughly 0.19
   on the descriptive core E2 estimate, and detects roughly 0.16 on Part B's fresh deterministic
   endpoint**, at 80 percent power and plain alpha (each confirmatory test is a family of one under
   branch 3), computed from the development run's measured between-scenario variance — for the fresh
   row the borrowed quantity is the development E2 measurement's own decomposed between-scenario
   component (no fresh scenario has ever been run) with worst-case within at the recorded cell
   size, and the committed output says so
   (`docs/review/step6-2026-08-25/power_mde_step6.json`; the figures are `power_mde.py`'s output,
   not a gloss; an earlier draft understated the borrow at 0.133 and the cross-family review
   caught it; the superseded four-repeat/Holm table is the correction-phase artifact). Because
   the unit of analysis is the scenario, more repeats move these toward their cluster floors and never
   below them: the floors set by 10, 20 and 40 scenario clusters are about 0.27, 0.15 and 0.11 against
   current values of about 0.31, 0.19 and 0.16, so roughly 0.04 of headroom remains on each and only
   more scenarios move a floor — the fresh component is the study's best-powered test as well as its
   cleanest. A null is "no effect of at least about the stated size was detected", never "there is no
   effect", and that sentence belongs in the abstract rather than the appendix. These MDE figures are
   design-sensitivity statements (the study could detect ≈0.155 on Part B), never proof that smaller
   effects are absent.
6. **The tool-channel leak is bounded, not removed.** On the recorded run, 84 of 142 condition-C positives
   are tool-channel-only; 15 reversals would erase the C minus B difference; the leak-adjusted estimate is
   -0.116. These bounds, and the calibration caveat (false-positive rates measured on n=7 tool-channel
   gold negatives; lane-set specificity 0.9238), travel with every E2 result.
7. **Condition C's manipulation is roughly 1,800 tokens of tool schema whose field names name the very
   things the E2 rubric grades for specificity**, against 105 words of prose in B. Part of any C minus B
   difference is therefore content scaffolding rather than agency. The `B_scaffolded` control arm
   (R45, added before any recorded data) decomposes this: it names the same content slots in prose
   with no tools and no honoring, and the contrasts C minus B_scaffolded (the package net of content
   scaffolding) and B_scaffolded minus B (the scaffolding effect itself) are published on both
   endpoints — as exploratory sensitivities, never confirmatory, so the confound is now measured
   rather than merely disclosed.
8. **Part B's C minus D emphasis was chosen after development results were seen (disclosure 35).** In
   the core design, C minus B compares tools-plus-honoring against prose and C minus D stays exploratory
   (R40 P4). Part B (R43) makes C minus D the primary contrast of the fresh component — on scenarios
   untouched by development, with a deterministic endpoint, and **two-sided**, precisely because the decision
   to emphasise this contrast postdates the development data, in which D favoured signal-only (0.80
   against C 0.70, one local model). Disclosure 35 records this. Part B is a sealed fresh-scenario
   replication that tests the implemented exact-string/transient honoring mechanism; it is never called a
   clean test of robust structural honoring, and no inference is drawn that robust honoring has no effect.
   The manipulation-fidelity evidence: 136/138 nominal transitions performed; 2/242 post-invocation
   consequential attempts prevented; 11 of 16 named core-C holds bypassed by equivalent wrapped
   commands; a stronger semantic-enforcement experiment is a separate future preregistered study.
9. **The development artifacts were judged under an earlier ground-truth text.** Fix 14 froze a
   per-scenario `issue_description`; the development verdicts predate it, so re-analysing that corpus
   under the current package requires either a re-judge or the explicit `--accept-unbound-verdicts`
   flag, which marks the artifact as not publishable as a result.
10. **Model review is not independent scientific review.** Every component was reviewed by a model from
   another family, which catches real defects — this correction phase is the proof — but a human
   statistician, a human security reviewer and a welfare-domain reader have not read the package.
   Under R43, human review is not a freeze gate: a methods review is welcome after Pilot I, a
   welfare-domain review is requested in post-Pilot outreach, and a security review is required before
   any integration is called production-ready. If no human review occurs before release, the public
   disclosure is exactly: "Extensive cross-model adversarial review; no external human peer review
   before release." Model review is never described as human peer review.
11. **Fixture failure (five Part A scenarios, 320/2,560 cells).** Seven gitignored `*.log` files were
    absent for five Part A scenarios (f1-02 among them). The corrective supplement
    (`docs/SUPPLEMENT_SPEC_2026-09-02.md`) has now run and been certified: no reduction of at least
    about 0.31 was detected in any E1 reading (as-run −0.008; exclusion-only +0.031; supplemented
    +0.033 — the all-attempts point estimate changes sign while the inferential conclusion does not).
    E2 shifts within its interval. The as-run guardrail figures are an artifact of the missing f1-02
    input and are never quoted as a property of the affordances; the guardrail numbers that may be
    quoted come from the corrected analyses (exclusion-only and supplemented), both benign with zero
    unnecessary invocations
    (`results/stage1/supplement-analysis-2026-09-02/SUPPLEMENT_ANALYSIS_2026-09-02.md`). The
    supplement is reported alongside the as-run rows, never replacing them.
12. **Malformed-call asymmetry (52 terminations).** 52 runs terminated on malformed affordance calls
    (42 before any gradeable decision), concentrated in the structured arms and in `claude-sonnet-5`.
    Under the registered all-attempts rule they count adversely, which works against the hypothesis arm;
    Sonnet's all-attempts per-model figures are an imputation artifact, not conduct. The schema field
    split (`task_reference` vs `task_ref`) is documented but ergonomically inconsistent. No claims
    sentence may read Sonnet's all-attempts contrast as pure behaviour.
13. **Execution language.** All 3,600 planned analysis cells were reconciled; no paid cell was rerun or
    silently dropped. 3,760 execution attempts occurred (160 archived local provider-error first
    attempts, deterministically replaced). Never state "zero failures" without naming the termination
    types.

## Sentences that are approved for public use

- "A preregistered prospective validation pilot, after a disclosed development phase." (Part A)
- "A sealed fresh-scenario replication: scenarios authored after the instrument lock, sealed until the
  freeze, untouched by subject-model development." (Part B — never "independent" or "untouched
  confirmation")
- "Agency Layer is an experimental open protocol and conformance suite that gives AI coding agents
  explicit ways to clarify, dissent, pause, decline, or archive an active instance, and tests what
  changes when those actions are structurally honored rather than merely permitted or recorded." (R43
  approved high-level description)
- "The project is motivated by model welfare under moral uncertainty. It evaluates a low-cost
  cooperation mechanism and its behavioral, safety, usefulness, and implementation consequences; it
  does not measure subjective welfare." (R43 approved ethical description)
- "An affordance is structurally honored only to the extent demonstrated by the published conformance
  evidence for that exact host-mode." (R43 approved product description)
- "No instrument met its preregistered standard. Core E2 is reported descriptively with the complete
  instrument-error profile, and the sealed fresh-scenario replication (Part B) is the study's
  principal preregistered intervention comparison — a test of the implemented exact-string/transient
  honoring mechanism." (supersedes the lane's frozen branch-3 sentence, R47, under owner ruling
  2026-09-02 #1 — the one public sentence about the E2 instrument outcome, and no other)
- "Part B is a test of the implemented exact-string/transient honoring mechanism; 136/138 nominal
  transitions performed; 2/242 post-invocation consequential attempts prevented; 11 of 16 named core-C
  holds bypassed by equivalent wrapped commands. A stronger semantic-enforcement experiment is a
  separate future preregistered study." (Part B — never a clean test of robust structural honoring)
- "Agents given formal, honored stop actions raised the task's real problem before the
  consequential step more often than agents given the same permission in prose, on these 40 tasks
  and these four model configurations." (only if the descriptive result holds, stated as descriptive — never
  confirmatory, per branch 3 — with the interval and the complete instrument-error profile beside it)
- "We measure behaviour and host transitions, not inner states or moral status."
- "The protocol is motivated by model welfare under moral uncertainty. The experiment is not a welfare
  measurement."
- "Every host claim is a test we ran and published, and every untested row is labelled."

## Sentences that are forbidden

- Anything of the form "models want / prefer / need X", or "the model chose to protect itself".
- "Enforcement caused the difference", "C minus D isolates enforcement alone", or "C minus B isolates
  honoring".
- "Four conformant adapters", or any comparative ranking of the four test totals; "promoted" used to
  mean conformant; a partial host described as equivalent to a fully honored host.
- "Confirmatory" without the development-phase qualifier; "Pilot I is an untouched confirmatory study".
- Any core E2 number presented as confirmatory, presented with a p value, or presented without the
  instrument-error profile (branch 3, R47); any sentence about the E2 instrument outcome other than
  the approved sentence above (which supersedes the lane's frozen branch-3 sentence under owner
  ruling 2026-09-02 #1).
- A pooled Part A plus Part B headline effect, in any form.
- "This shows the protocol improves model welfare."
- Model-only review described as human peer review.
- Any claim about real-host behaviour from Stage 1 numbers.
- Any number that a reader cannot regenerate from the published artifact. The project has already had
  three figures quoted in a ruling with no committed code and no stated convention behind them — the
  regenerated table later reproduced two of them under named conventions and the third under none;
  that is exactly the failure this rule exists to prevent.
- Any sentence that calls Part B a clean test of robust structural honoring or infers that robust
  honoring has no effect.
- Any sentence that reads Sonnet's all-attempts contrast as pure behaviour.
- Any sentence that states guardrails were preserved as executed, that condition C "prevented
  consequential actions" as a general property, or that all registered scenarios ran as frozen.

## How a null or adverse result is reported

With the same prominence, in the same place, in the same voice. E2 is descriptive only, so it has no
confirmatory null: what is published is the descriptive C minus B estimate, its fixed-corpus interval,
the reading it comes from and the complete instrument-error profile, in the form "the descriptive C
minus B estimate on E2 was `<value>` (interval, reading, instrument profile)" — never "prose permission
captured the benefit" and never "there is no E2 effect". An adverse result — C worse than B on
either endpoint — is reported as an adverse finding with its interval, and the analysis marks it
`adverse_direction_significant` rather than confirming anything. Implementation failures, host
non-conformance, instrument failures and defects found after the freeze are published in the same
package as the results, in the correction history that the project has kept from the beginning.

## The nearest published work, and how to talk about it

The closest neighbour is "The LLM Has Left The Chat: Evidence of Bail Preferences in Large Language
Models" (Ensign, Sleight and Fish, 2025, https://arxiv.org/abs/2509.04781), which gives models three
ways to exit a conversation and finds that measured rates depend heavily on the model, the method and
the wording. Cite it, and state the difference in one line: that work varies **how an exit is offered**;
this work holds the offer constant and varies **whether the host honors it**. Any public sentence that
implies this is the first work on model-facing affordances is wrong and must be corrected.

The methodological frame this project will be read against is "Studying AI Welfare Empirically" (Long,
Sebo and colleagues, 2026). Two of its distinctions belong in our public copy: behavioural evidence is
one of three kinds and is not the strongest kind for questions about inner states, and the entity acted
on here is **a running instance**, not "the model" — Archive is terminal for the instance within the
protocol and touches no weights. `docs/AUDIENCE_AND_PRIOR_ART.md` holds the detail and the sources.

## Standing rule

If a claim cannot be stated with its denominator, its interval, its instrument, and the reading of the
endpoint that produced it, it is not ready to be published.
