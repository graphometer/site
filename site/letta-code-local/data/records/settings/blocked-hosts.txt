# blocked-hosts.txt : names a CONNECTED window turns away.
# The connected launcher writes each of these into the sandbox's own /etc/hosts as 0.0.0.0 and :: .
# Those two addresses mean THIS COMPUTER: a call to a blocked name lands on the laptop's own port (443 or 80),
# where nothing answers, and fails at once. (If a web server were ever run on this laptop, it would receive
# such calls.) One name per line. Lines starting with # are notes. The launcher refuses to open the connected
# window if letta.com or api.letta.com is missing from this list.
#
# THE LIMITS, plainly: this blocks NAMES, not addresses, and only the names listed (a hosts file has no
# wildcards: "anything.letta.com" is not covered by "letta.com"). A program that already knows one of Letta's
# numeric addresses, or that asks a name server directly, is not stopped. It keeps the engine's own calls home
# from leaving; it is not a wall around what an agent's command can do. The keys are the real gate.
#
