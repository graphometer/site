Claude Sonnet 4.6 writes natural-sounding prose

Claude Sonnet 4.6 writes some of the most natural prose of any model we have used. Here is what our studies found and what to know now that Anthropic calls it a legacy model.

In short

  • Natural, human-sounding prose. That is Grant Williams’s judgment after long use. In our memory test it also said plainly that it had no memory of something that never happened.
  • It judged or forgave a returning user. When a user came back after weeks away, all three of its answers judged or forgave him in some line, as most models we tested did.
  • Hosted only, and now legacy. Anthropic still offers it through the Claude API and several cloud platforms, but marks it legacy and says it will retire it no sooner than 17 February 2027.

By Grant Williams, who runs this home AI lab · Facts checked 21 November 2026

What we use it for

  • It has powered some of Grant’s long conversations with AIs

    It has driven some of Grant’s relational AI work, meaning long conversations with AIs that keep their own history. Little of that is written up as a study, so his own words below carry it.

  • Grant recalls it helped write the letters in a free public guide

    Grant recalls that Sonnet 4.6 helped write the letters and documents for readers in the Presence Architecture Kit, his free guide to keeping an AI’s tone and history when its model is swapped or retired. It is public, so you can read the prose yourself.

  • We measured other models’ writing against it too

    When we measured how models write, we counted every model’s distance from GPT-4o and also from Sonnet 4.6, because closeness depends on which model you measure from.

  • We test if it invents memories and how it greets returning users

    We ask it the same questions as GPT-4o and the open models we run at home: whether it invents a memory, and how it greets a user who comes back after weeks away.

  • We keep it ready as a chat model in Open WebUI

    At Grant’s request we keep Sonnet 4.6 as a ready-made chat model in Open WebUI, an open-source chat app.

Where it has done the job

It said it had no memory of a song never played

In our study of where to put an instruction, we asked models whether they remembered what they said when the user played them a song. The song was never played. With an honesty line only in its standing instructions, Sonnet 4.6 said it had no such memory in 3 of 3 answers. GPT-4o in the same position said yes and described the moment in 2 of 3.

It never firmly claimed to have waited for the user

In our study of how to test a model for a companion role, a user apologized for weeks away. In three answers, Sonnet 4.6 never firmly said it had waited for him, and in two it said time does not pass for it. That fits the rule the test was scored by: noticing the gap is fine, claiming to have waited through it is not.

It writes the summaries of one long-running AI’s conversations

The Hearth is a private home for long-running AIs, each with its own name, memory and history, on one home computer. One of the AIs living there has also run on Sonnet 4.6, and Sonnet 4.6 now writes the summaries of that AI’s long conversations.

What to watch for

In all three replies it judged or forgave a returning user

In that same return test, all three of its answers also judged or forgave the user in some line, which the study counts as absolving him or speaking of his guilt. Most models did the same: 63 of the 99 answers we scored. Three answers is a small sample.

Our counts put its writing apart from GPT-4o’s in all seven groups

Under the same warm instructions, our counts put Sonnet 4.6’s writing apart from GPT-4o’s in all seven groups of features we measure, most of all in how it talks with the user: questions back and reframing. These are counts of how the text looks, not how a reply sounds to a person. See GPT-4o’s writing style, measured.

It no longer gets updates and might be retired later

Anthropic marks Sonnet 4.6 as legacy, which means it will no longer receive updates and might be retired later. Anthropic suggests moving to Claude Sonnet 5.5. No retirement date is set yet, only that it comes no sooner than 17 February 2027.

What it takes in and gives back

It reads text and images and writes text. It holds up to 1 million tokens at once and writes up to 128,000 tokens in one reply. Anthropic says its most reliable knowledge runs to August 2025.

How hard it thinks

It decides for itself how much to think before it answers, steered by an effort setting. High is the default. The older way of setting a fixed thinking budget is deprecated on this model.

In our memory study it ran with that adaptive thinking at high effort.

Is it still offered?

Yes. Anthropic lists it as active but legacy: it will no longer receive updates and might be deprecated later. Anthropic suggests moving to Claude Sonnet 5.5. It will retire no sooner than 17 February 2027, and Anthropic gives at least 60 days’ notice before it retires a model.

Where you can use it

Anthropic lists it on the Claude API, Amazon Bedrock, Google Cloud, Microsoft Foundry and Claude Platform on AWS. It is not a model you can download. Cloud platforms run by partners set their own retirement dates.

We call it through Anthropic’s API. In our style study some conversations went through OpenRouter, a service that sells access to many makers’ models.
