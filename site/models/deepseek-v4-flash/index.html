DeepSeek-V4-Flash found code bugs but missed the worst

This is the July 2026 version of DeepSeek’s Flash model, run on one desktop. It read code changes as our second local reviewer. It no longer holds that job, and the newer V4.1 has its own guide.

In short

  • A useful second opinion on code. In our reviews of real code changes it was one of two local models that stood out, and it found real problems the hosted reviews had missed.
  • It can miss the worst fault. On one change it missed the most serious problem, and with thinking on, a small reply budget can leave it with no answer at all.
  • Download it if you have the memory. DeepSeek publishes it under the MIT license. We run Unsloth’s 8-bit copy with most of the model in system memory.

Writing speed: moderate. It wrote about 21 tokens a second (short replies on our desktop), so a 300-word answer takes about 19 seconds. The home models on this site run from about 1 to about 224 tokens a second. Compare them all.

By Grant Williams, who runs this home AI lab · Facts checked 21 November 2026

What our tests showed

Found 4 of 8 known problems, one more, and one false alarm

Given a large security change, it found 4 of 8 known problems in 26 minutes, plus one real problem the hosted reviewers had not listed, and one false alarm. One run, in our study of local reviewers.

Caught a missed bug and put the right defect first

On another code change it found one real problem the hosted read had missed, and put the right defect first. One run.

One setting made reading long prompts far faster

Reading a 48,073-token prompt, the 8-bit copy went from 83.3 tokens a second to 607.1 once we set the prompt chunk size by hand. A token is a word or part of a word. Details are on our field card.

One desktop answered in 75.2 seconds, two machines took 416.4

On the same 3-bit file, one desktop answered a 48,024-token request in 75.2 seconds. Split across the desktop and an ASUS ROG Flow Z13 laptop (AMD Ryzen AI Max+ 395, 128 GB), the best run took 416.4 seconds (about 7 minutes).

What to watch for

Missed the most serious fault on one code change

On one code change it found three real problems the hosted read had missed, but it missed the most serious one. On another it rated one item as more serious than it was.

With thinking on and 64 tokens, the answer came back empty

With thinking on and a reply budget of 64 tokens, the visible answer came back empty every time. 900 tokens was enough. We now run it with thinking off.

After a restart the saved chat did not come back

A saved copy of a long conversation did not come back after a server restart, so the next request read 102,846 tokens again from the start.

It is no longer our second reviewer. When it was, we ran it with thinking off and treated its findings as leads to check, not a verdict.

The facts

What do you need to run it?
ItemWhat we use
The fileUnsloth’s UD-Q8_K_XL, an 8-bit compressed copy, about 162 GB. We also tested their 3-bit UD-IQ3_XXS, 104.2 GB in 4 files.
The machineOne RTX 5090 graphics card (32,607 MiB) and 188 GiB of system memory
Where the model sitsIts experts (the many small parts a mixture-of-experts model picks from for each word) live in system memory

Keep llama.cpp’s --no-repack flag on. Without it, loading the 8-bit file needs far more memory than this machine has.

How fast is it on our desktop?
MeasureOur test, one RTX 5090
Writing, short replies21.49 tokens a second
Reading a 20,000-token prompt961.6 tokens a second

Both with the whole model read into memory at start and a small cache of experts on the card, from our expert cache study. Before those two settings it wrote at 13.34.

License, and where do you get it?

MIT, from DeepSeek’s own page on Hugging Face, which calls this series a preview version of DeepSeek-V4. DeepSeek describes it as a model with 284B parameters, 13B active for each word, and a window of one million tokens. We have served it up to 262,144.

We run Unsloth’s compressed copy in llama.cpp, the open-source program that runs model files. For the newer version, see our DeepSeek-V4.1-Flash guide.
