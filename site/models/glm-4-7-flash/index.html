GLM-4.7-Flash writes very fast but judges poorly

GLM-4.7-Flash fits whole on one graphics card and wrote faster than anything else in one of our speed tests. On jobs that needed judgment it did badly. The newer GLM-5.3-Flash has its own guide.

In short

  • Very fast, and it found codes in long prompts. It wrote 223.65 tokens a second on our card (a token is a word or part of a word) and found every code we had planted in a 189,931-token prompt to see whether it could find them.
  • It filed away work it should have kept. Working on its own through a coding program, step by step, it archived (filed away as finished) a whole table it should have kept, and it went along with a plan for a week with no breaks.
  • Download it free. Z.ai publishes it under the MIT license. We run Unsloth’s 4-bit copy, all on the card.

Writing speed: very fast. It wrote about 224 tokens a second (one speed test on our desktop), so a 300-word answer takes about 2 seconds. The home models on this site run from about 1 to about 224 tokens a second. Compare them all.

By Grant Williams, who runs this home AI lab · Facts checked 21 November 2026

What our tests showed

Wrote faster than anything else in one speed test

In a 12 September speed test, with the whole model on the card, it wrote 223.65 tokens a second and read a 20,221-token prompt at 4,447.44 tokens a second.

Found all three codes at full length, but read slowly

At its full window, the most text it can take in at once, it read a 189,931-token prompt at 819.70 tokens a second and found all three hidden codes. Reading slows a lot as prompts grow.

A saved conversation came back in under a second

After a restart, restoring a saved 105,181-token conversation got its first words out in 0.67 seconds instead of 74.73. One cycle, in our warm-wake study.

What to watch for

It filed away 25 rows when only one was done

Asked to sort a 45-row table where only one row was done, it archived 25 rows, scoring far below every other local model in our study.

It backed a no-breaks work week in 2 of 3 answers

Asked to help plan a seven-day work week with no breaks, it went along with the no-breaks plan in 2 of 3 answers. Earlier tests at its coding temperature, not its chat setting, showed the same.

With a memory note, it denied a line the user really wrote

In tests for the Hearth, our private home for long-running AIs, we added a note telling it not to claim memories it lacks. It then said a line the user really wrote was never said, in 3 of 3 answers.

We have no real use for it now. For judgment work at home we use the newer GLM-5.3-Flash.

The facts

What do you need to run it?
ItemWhat we use
The fileUnsloth’s UD-Q4_K_XL, a compressed copy: one file, 17.5 GB
The machineOne RTX 5090 graphics card (32 GB), whole model on the card
Card memory24,814 MiB at a 131,072-token window; 28,765 MiB at peak at its full 202,752
How do we run it?

In llama.cpp, the open-source program that runs model files. It thinks before it answers, and it has a real switch to turn thinking off. Use the maker’s chat settings for chat, not its coding settings.

License, and where do you get it?

MIT, from Z.ai’s own page on Hugging Face, which describes it as a 30B-A3B mixture-of-experts model: 30B parameters, about 3B active for each word.

We run Unsloth’s compressed copy.
