MiniMax-M3 found three faults but wrote slowly

We ran MiniMax-M3 on one desktop until 30 October 2026, when we dropped it. Given a four-file change with four known faults it found three in 12 minutes; GLM-5.3-Flash, the local model we kept, found all four in 8 minutes.

In short

  • It found three of four known faults in one code review. On a four-file change with four known faults it found three in 12 minutes. GLM-5.3-Flash, the local model we use for code review, found all four in 8 minutes on the same change.
  • It wrote 8.9 and 9.0 tokens a second on short answers. A token is a word or part of a word. Keeping the program on our processor’s fast cores took one longer reply from 8.43 to 10.79 tokens a second. We stopped running it on 30 October 2026 and deleted our copy.
  • Free for non-commercial use. MiniMax’s license allows non-commercial use; commercial use needs a notice, and written permission above 20 million US dollars of yearly revenue. We ran bartowski’s compressed copy of it, published in the file format llama.cpp reads.

By Grant Williams, who runs Graphometer · Facts checked 27 November 2026

What our tests showed

It found three of four faults in a code change

From 10 to 12 October we gave several local models a four-file change with four known faults, as one plain request, with no way for them to run the code or look anything up. MiniMax-M3 found three of the four faults, and its own run took 12 minutes. Our record also notes one arithmetic slip in its report, without saying where. GLM-5.3-Flash, the local model we use for code review and still run, found all four in 8 minutes on the same change. MiniMax-M2.7, an older model from the same maker, found none and called the change fine. One run each.

It found all three codes we planted in a long prompt

With bartowski’s compressed copy, a 131,072-token window (the most text it can take in at once) and an 8-bit cache, the memory that holds what has already been said, it gave back all three codes we had planted in a 58,307-token prompt to see whether it could find them. The whole request took 300.2 seconds, about 5 minutes. One run.

Keeping it on the fast processor cores raised its writing speed

With 48,086 tokens already in the conversation, we ran it twice. The second run kept llama.cpp on the eight fast cores of our desktop processor, with three settings. A 602-token reply came out at 8.43 tokens a second without them and 10.79 with them. One run each.

What to watch for

Our first download could not use its long-text shortcut

MiniMax-M3 has a way of reading long text that looks at part of the input rather than all of it; the name for it is sparse attention. The first file we downloaded was built before llama.cpp, the open-source program that runs model files, supported that shortcut, so it ran without it. We switched on 21 September 2026 to a file that carries the parts the shortcut needs, and every number on this page comes from that file.

At the longest window we tried it would not load

At 262,144 tokens with an 8-bit cache and part of the model kept on the main processor, three setups ran out of graphics-card memory before producing any result. We did not test other setups. We ran it at 131,072 tokens.

It wrote under 10 tokens a second on short answers

On short answers it wrote 8.9 and 9.0 tokens a second on our desktop, without the fast-core settings above. One run each.

We stopped running it on 30 October 2026. Our own record gives the reason: it read more slowly than GLM-5.3-Flash, which we kept, and on the same code review it found one fault fewer. We no longer have it installed here; MiniMax’s files are still public if you want to try it.

MiB and GiB are the units the program reports memory in. A GiB is a little larger than a GB.

How fast was it?

Short answers came out at 8.9 and 9.0 tokens a second on our desktop, with a 131,072-token window and an 8-bit cache. A prompt of 3,658 tokens was read at 147.5 tokens a second.

License, and where do you get it?

MiniMax’s page on Hugging Face lists the license as minimax-community. It allows non-commercial use free of charge. For commercial use you must show “Built with MiniMax M3”. Above 20 million US dollars of yearly revenue you need MiniMax’s written permission; below that you send MiniMax a one-time notice. The license also lists uses it forbids, military use among them.

MiniMax’s own download is the full model. We ran bartowski’s compressed copy in llama.cpp, the open-source program that runs model files.
