Nemotron 3.5 Bolt is fast but missed bugs

Nemotron 3.5 Bolt is an open model from NVIDIA that reads text and images. NVIDIA’s own compressed file fits on one 32 GB graphics card and writes very fast. In one code review it approved code with four known problems.

In short

  • Very fast on one graphics card. With NVIDIA’s small draft model beside it (a helper that guesses the next few words for the big model to check), it wrote 184.91 tokens a second after reading a 190,620-token text, and read that text in 62.8 seconds. A token is a word or part of a word.
  • It approved faulty code in a review. So we plan to use it for a quick first pass, never as the reviewer whose word decides.
  • Free to download. NVIDIA publishes it under the OpenMDW-1.1 license, with its own compressed files. We run NVIDIA’s 2-bit file, about 22 GB, and its draft model.

Writing speed: very fast. It wrote about 148 tokens a second (a short reply with its helper model, one run on our desktop), so a 300-word answer takes about 3 seconds. That time is worked out from the writing speed, not timed. The home models in our speed table run from about 1 to about 224 tokens a second. Compare them all.

By Grant Williams, who runs Graphometer · Facts checked 21 November 2026

What we plan to use it for

  • It is set up for chat and for step-by-step tasks

    It is connected to the Hermes agent program (where a model works on its own through a task, step by step, with tools) and to our Open WebUI chat pages. We have not used it much yet.

What our tests showed

It found a code word planted in a very long text

It read a 190,620-token text in 62.8 seconds and then found the code word we had planted in it. It also found the code in a 58,936-token text. One run each.

It fit on one 32 GB card at its largest text limit

The model, its draft model, its image reader and a 262,144-token window (the most text it can take in at once) used 31.4 GB of the card at the fullest point, about 1.2 GB to spare.

It got all 15 memory-tool tasks right and passed a coding test

Memory tools let a model save and change its own notes. It also used what a tool sent back correctly, and passed a small coding test with thinking off and with it on. One run each.

The image check went only as far as naming red and blue

Asked about a red test image and a blue one in our chat pages, it named both colours. The check went no further. One run.

What to watch for

It approved faulty code and missed the worst bug in another review

On a review of about 25,000 tokens with seven known defects it found four or five in 76 seconds, but missed the most serious one. On a smaller change with four known problems it found none and said the change was fine. One run each.

A larger download stayed closer to the original model in one test

On the same public text, a larger 4-bit copy made by Unsloth scored lower than NVIDIA’s 2-bit file on perplexity, a measure of how surprised a model is by text: 3.0970 against 3.2931. Lower is closer to the original model.

On our laptop it wrote slower than two smaller models

On an ASUS ROG Flow Z13 laptop, without the draft model, it wrote 25.45 tokens a second after reading a 58,936-token text. That was slower than the two smaller models the laptop already runs. With the draft model, ordinary writing got slower there.

Our tests point to quick first passes and fast step-by-step tasks, never the deciding review. It is set up for that, and we have not used it much yet.

The facts

What do you need to run it?
ItemWhat we use
The fileNVIDIA’s 2-bit GGUF, about 22 GB, plus NVIDIA’s draft model, about 1 GB, and its image reader file
The machineOne RTX 5090 graphics card (32 GB); the whole model sits on the card
Card memory30.6 GB idle, 31.4 GB after reading a 190,620-token text

A draft model is a small model that guesses the next few words for the big one to check, which speeds up writing.

How fast is it?

On an ordinary short reply, 120 tokens of prose with no thinking, it wrote 148.5 tokens a second. Conditions: our desktop, NVIDIA’s 2-bit file with its draft model, a 262,144-token window, 17 October 2026, one run. Because of the draft model, its speed depends on how predictable the text is.

How do you switch thinking off?

It thinks by default. Send enable_thinking: false in the chat template settings of your request to turn it off for that request.

What license is it under, and where do you get it?

OpenMDW-1.1, from NVIDIA’s own pages on Hugging Face. NVIDIA describes it as a vision-language model for everyday agent tasks run locally, with 74B parameters in total and 9B active, and a window of up to 256K tokens. NVIDIA’s 24GB version uses a native 2-bit format; that is the GGUF file we run.

From NVIDIA’s model pages on Hugging Face, read 21 November 2026, and our own measurements.
