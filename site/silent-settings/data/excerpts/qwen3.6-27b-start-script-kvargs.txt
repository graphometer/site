Qwen3.6-27B start script: the 262,144 rung promised an 8-bit cache and its launch line expanded an array
nothing ever assigned. Excerpts of two versions of the same script, with their line numbers. Paths, the
bridge address and the settings-variable prefix are redacted as data/README.md states; em dashes in our own
comment and message lines became colons (counted there). Nothing else is changed. The comment on line 77 (line
90 in part B) carries figures of its own, 27,947 MiB, 71.8 t/s, "healthy in 13 s" and a 16 GB f16 cache: they
are the script's comment, no log in this package shows the run behind them, and the page does not use them.

Backup copies are named for the day they were taken; a copy's file time is the last time the script had been
edited before that day. So "bak-20260921-141932" (file time 2026-09-17 16:10) is the script as it stood from
17 September 16:10, and "bak-20260926-256k" (file time 2026-09-21 18:37) is the script as it stood until
the 26 September edit that added the assignment.
