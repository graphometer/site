==== What it means, reproduced on 2026-09-26 with a two-line demonstration file that contains only FOO_PORT=8116
$ FOO_PORT=8199 bash -c '. demo.env; PORT="${FOO_PORT:-8116}"; echo ...'
exported FOO_PORT=8199; after sourcing the file the script sees FOO_PORT=8116 and binds 8116
exit code 0

Reading: sourcing runs the file's assignments in the script's own shell, so a plain NAME=value line in the file
replaces whatever the environment carried, and the script then reads the file's value. Nothing prints. The file
winning is the design of these scripts (the file is the operator's control surface); the trap is expecting an
exported variable to win.
